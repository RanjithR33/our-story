# Our Story ❤️

A premium romantic website built with React 19, Vite, TypeScript, Tailwind CSS v4, and Framer Motion.

## Features

- **Hero** — Full-viewport animated gradient, floating hearts, parallax, CTA
- **Timeline** — Alternating glassmorphism cards with scroll reveal
- **Gallery** — Pinterest masonry layout with fullscreen lightbox & keyboard nav
- **Wrapped** — Spotify-inspired stat cards with count-up animations
- **Love Reasons** — 50 flip cards with 3D animation
- **Love Letter** — Typing animation, handwritten style, editable content
- **Future Plans** — Interactive bucket list cards
- **Memory Map** — Interactive markers with popup memories
- **Statistics** — Luxury dashboard with animated numbers
- **Final Section** — Starry sky, sequential text reveal, confetti, scroll-to-top

### Global

- Dark mode with persistent storage
- Floating music player widget
- Animated scroll progress bar
- Heartbeat loading screen

## Getting Started

```bash
cd our-story
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19 + TypeScript
- Vite
